# Phase 6 设计 - 知识库文件中心

## 目标与非目标

本工作段把知识库管理从 RAGFlow 数据集操作台改成面向管理员的文件中心。管理员按文件名、上传日期、资料类别和处理状态筛选文件；上传时只选择资料类别；服务端把类别映射到对应 RAGFlow 解析策略和内部数据集。页面不展示真实 dataset 名称、dataset ID、chunk method、chunk 数量或检索片段。

文件条目提供整页预览。服务端通过管理员鉴权代理 RAGFlow 原始文档下载；网页对 PDF、图片、HTML 和纯文本使用受限预览，对浏览器不能原生显示的 Office 等格式提供下载。基础实现继续提供失败重试和删除，不新增 OBS 存储。只有在 RAGFlow 实例无法提供原文件下载时，后续才评估 OBS。

非目标包括本地文档镜像表、本地解析或分块、chunk 查看、让用户创建/删除数据集、检索预览、纠错答案发布，以及改动在线问答四路径边界。

## 受影响模块

- `biosafe/integrations/ragflow/models.py`：归一化文档创建/更新时间。
- `biosafe/integrations/ragflow/client.py`：增加原始文档下载接口及时间字段兼容。
- `services/api/routes/admin.py`：增加文件聚合列表、分类上传、预览下载、重试和删除接口；保留既有低层接口兼容测试/运维。
- `services/api/schemas.py`：增加不暴露数据集细节的文件中心响应 schema。
- `web/src/KnowledgeAdminPanel.tsx`、`web/src/styles.css`：改成文件中心列表、筛选、上传弹窗和预览抽屉。
- `tests/contract/test_ragflow_client.py`、`tests/integration/test_admin_api.py`、`web/src/App.test.tsx`：覆盖下载契约、隐藏数据集信息和关键交互。

## API 与状态映射

新增面向页面的接口：

- `GET /api/admin/knowledge/files`：聚合受管 RAGFlow datasets 下的文件，支持 `name`、`category`、`status`、`date_from`、`date_to`。
- `POST /api/admin/knowledge/files`：multipart 上传，字段为 `file` 和 `category`；服务端查找或创建该类别的内部 dataset，并自动发起解析。
- `GET /api/admin/knowledge/files/{document_id}/content`：鉴权代理原文件，使用 inline disposition 供预览，也可带 `download=true` 下载。
- `POST /api/admin/knowledge/files/{document_id}/retry`：失败或取消后重新解析。
- `DELETE /api/admin/knowledge/files/{document_id}`：删除文件，不允许由页面删除内部 dataset。

固定类别映射为：法规标准 `laws`、SOP 与设备手册 `manual`、名录与表格 `table`、论文与报告 `paper`、通用资料 `naive`。页面状态统一为：`uploaded`（已上传/待处理）、`parsing`（解析中）、`completed`（已完成）、`failed`（失败）。RAGFlow 原始状态和失败消息只用于服务端归一化，不把实现术语暴露给用户。

`KnowledgeFileItem` 只返回 `id, name, category, category_label, status, status_label, progress, status_message, size, created_at, updated_at, preview_kind`。dataset 身份在每次操作时由服务端实时从 RAGFlow 查找，不写入 SQLite，不建立第二事实源。

## 风险、回滚与验证

- RAGFlow 文档下载端点可能因版本不同而变化：adapter 固定公共 API 路径并用 contract test 验证，同时对当前实例执行只读下载探测。
- 聚合列表需要读取多个内部 dataset：首批仅五类模板库，使用并发读取；页面轮询只在存在解析中文件时启用。
- HTML 文件可能包含主动内容：预览 iframe 使用 sandbox 且不开放脚本、表单和同源权限。
- 浏览器不能预览部分格式：不伪装成功，明确切换为下载入口。
- 分类库不存在时上传会创建 `biosafe-dev-{method}`；若同策略已有受管库则复用，避免每文件建库。

回滚本工作段时可移除文件中心接口和新 UI，既有 dataset/document 管理接口仍可使用；无 SQLite 迁移或远端批量变更。

```bash
conda run -n biosafe python -m pytest tests/contract/test_ragflow_client.py tests/integration/test_admin_api.py

```
