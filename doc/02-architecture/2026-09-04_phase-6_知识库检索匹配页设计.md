# Phase 6 设计 - 知识库检索匹配页

## 背景与目标

历史记录 20 显示，“生物安全中的办公区是指什么？”走了 RAG 路径，但只检索环境变量
`RAGFLOW_DATASET_IDS` 配置的通用资料库。新上传的 `1746698296999_79788.pdf` 位于法规标准库，
不在该默认范围内；对法规标准库单独执行相同查询时，目标定义也未进入当前 top 8。

本工作段在知识库管理页增加“检索匹配”入口和独立页面。管理员输入原始检索问题后，页面展示
在线 RAG 默认配置实际使用的数据集、top-k、相似度阈值、向量权重，以及 RAGFlow 返回的有序
chunk、来源文档和各类分数，用于定位检索范围和排名问题。

## 非目标

- 不修改在线问答四路径，不增加查询改写、embedding、BM25、RRF 或重排序。
- 不允许页面选择任意数据集或修改检索参数；本页只观察在线默认配置。
- 不调用答案合成 LLM，不生成答案，不写入问答历史或纠错记录。
- 不自动扩大 `RAGFLOW_DATASET_IDS`，也不修改远端 dataset、document 或 chunk。

## 受影响模块

- `biosafe/application/query_service.py`：提供默认 RAGFlow 请求快照，并让在线默认路径复用同一构造逻辑。
- `services/api/schemas.py`、`services/api/routes/admin.py`：增加管理员只读检索匹配契约与接口。
- `web/src/App.tsx`、`web/src/KnowledgeAdminPanel.tsx`：增加独立路由和知识库入口。
- `web/src/KnowledgeRetrievalPanel.tsx`、`web/src/styles.css`：实现检索输入、默认配置摘要和 chunk 排名列表。
- `tests/unit/test_query_service.py`、`tests/integration/test_admin_api.py`、`web/src/App.test.tsx`：覆盖配置复用、API 与页面交互。

## API 与数据

新增 `POST /api/admin/knowledge/retrieval-match`，需要管理员 Bearer token。

请求：

```json
{"question": "生物安全中的办公区是指什么？"}
```

响应包含 `question`、默认数据集的 `id/name/chunk_method`、`page_size`、
`similarity_threshold`、`vector_similarity_weight` 和按 RAGFlow 顺序返回的 `chunks`。
无默认数据集时返回稳定错误 `ragflow_dataset_not_configured`。接口无 SQLite 或远端写操作。

新增页面路由 `/admin/knowledge/retrieval`。管理员 token 继续使用现有 localStorage 项；未登录时返回
知识库管理页完成认证。

## 风险与回滚

- 页面展示 dataset/chunk 技术细节，仅位于管理员诊断页，不改变文件中心的业务视图。
- RAGFlow dataset 名称解析需要一次只读列表请求；若配置 ID 已不可见，仍以 ID 作为名称回退。
- chunk 内容可能较长，页面使用稳定排名列和可换行正文，移动端改为单列，避免布局溢出。
- 回滚时移除新 API、页面路由和入口即可；无数据迁移或远端资源需要回滚。
