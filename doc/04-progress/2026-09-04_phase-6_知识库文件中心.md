# Phase 6 工作段 - 知识库文件中心

- 状态：DONE（基础实现）；真实 RAGFlow 原文件只读下载探测通过。
- 范围：
  - 将知识库管理页从 dataset/chunk 操作台改为面向管理员的文件中心。
  - 支持文件名、上传日期、资料类别和处理状态筛选。
  - 上传时只选择业务类别，服务端自动选择或创建内部解析库并发起解析。
  - 支持 PDF、图片、HTML 和文本整页预览；浏览器不能原生预览的格式提供原文件下载。
  - 保留失败重试和文件删除，不在页面开放内部数据集管理。
- 关键设计：
  - 文件中心 API 只返回文件、业务类别和归一化状态，不返回 dataset 名称、dataset ID、chunk method、chunk 数量或检索片段。
  - 固定类别映射到 RAGFlow 的 `laws/manual/table/paper/naive`，RAGFlow 继续作为文档状态唯一事实源，不新增 SQLite 镜像表。
  - 原文件通过带管理员鉴权的后端代理下载；HTML 响应增加 CSP sandbox，网页 iframe 同时使用 sandbox。
  - 既有低层 dataset/document API 暂时保留给 smoke 和运维，不再由页面调用。
