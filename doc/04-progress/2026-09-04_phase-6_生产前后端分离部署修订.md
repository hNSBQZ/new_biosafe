# Phase 6 工作段 - 生产前后端分离部署修订

- 状态：IN_PROGRESS
- 原因：生产宿主机已有 Node 和 Nginx，前端应在宿主机打包为静态文件并由 Nginx 提供，不应放入 Python API 镜像。
- 范围：移除 Dockerfile 的 Node 构建阶段、镜像内静态产物和 FastAPI SPA 托管；更新 Compose、生产配置模板、Nginx 路由和升级流程；恢复旧前端 `VITE_API_BASE` 的开发直连/生产同源反代切换。
- 数据或接口兼容性：无 SQLite schema 和业务 API 变化；`/api/*`、`/health`、SSE 和 WebSocket 路径保持不变。删除仅用于 FastAPI 静态托管的 `BIOSAFE_WEB_DIST_PATH`。
- 验证方法：不在开发机创建容器或镜像；执行 Compose 配置解析、后端测试和静态检查、前端测试/lint/build，检查本机无项目 Docker 资源。
- 遗留问题：生产域名、证书、Nginx 配置路径和静态发布目录由生产机实际环境确认。
