# Phase 6 - 引用失败草稿日志检查点

- 状态：IN_PROGRESS
- 范围：为引用硬失败和句级 coverage warning 保留 LLM 草稿与引用诊断，并补齐所有 QueryFailure 的请求级日志；修复过严句级校验导致有效回答被丢弃的问题。
- 关键设计：至少一个引用和编号范围继续硬校验；标题、过渡语和资料不足说明不参与覆盖率；其他漏标句基于同一批 chunk 修复一次，仍漏标则记录 `rag_citation_coverage_incomplete` warning 并返回有效回答。日志使用结构化 `details`，不记录 chunk 全文或 RAGFlow raw metadata；所有字段在 JSON 格式化前递归脱敏。

- 数据或接口兼容性：HTTP/SSE/WebSocket 和 SQLite schema 不变；草稿只进入 Git 忽略的本地滚动日志，不进入知识库、在线回答或历史答案字段。
