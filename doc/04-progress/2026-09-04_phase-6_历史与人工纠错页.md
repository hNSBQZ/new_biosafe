# Phase 6 工作段 - 历史与人工纠错页

- 状态：DONE
- 范围：重构 `/admin/history` 的信息层级和纠错交互，保留既有历史、异步模型复核和人工纠错 API。
- 关键设计：历史默认为只显示问题和日期的单列条目；点开条目后显示“查看答案、自动纠错、人工标注”三个操作；三类信息分别进入弹窗。模型建议只能转入人工草稿，不自动 PATCH。

- 数据或接口兼容性：无 SQLite migration，无 API schema 变更。`corrected_answer` 非空仍表示已人工标注；清空后恢复未标注。修复了模型任务轮询时可能覆盖正在编辑的本地草稿的竞态。
