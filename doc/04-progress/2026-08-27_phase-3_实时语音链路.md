# Phase 3 - 实时语音链路

- 状态：BLOCKED
- 范围：
  - 新增 FunASR WebSocket adapter 和 HTTP TTS adapter，全部服务地址、模型与参数来自环境变量。
  - 新增单轮浏览器音频 WebSocket：`WS /api/v1/chat/audio`，兼容 `audio_start/audio_data/audio_end/interrupt`。
  - 新增 `AudioPipeline`，语音转写后复用 `QueryService.answer_text()`，不复制问答逻辑，不增加历史匹配、查询改写、本地检索或重排。
  - TTS 对 direct/RAG 文本做句子切分、文本归一化和有序音频分片发送；TTS 失败时保留文本回答和历史记录。
- 关键设计：
  - ASR、QueryService、TTS 分层隔离：ASR/TTS adapter 只返回稳定 `success/code/message`，WebSocket route 只做协议转换。
  - `input_mode` 在语音链路固定为 `voice`，历史仍由 QueryService 写入 `chat_history`，语音层不新增 SQLite 表。
  - QueryService envelope 通过 `query_event` 转发；instruction 额外发送 `instruction` 便捷消息，direct/RAG 额外发送 `answer` 和 `audio_stream`。
  - `interrupt` 通过 `AudioSession.is_interrupted` 传给 QueryService 的 `cancel_requested`，终态返回 `session_complete.reason=interrupted`。
